### github是什么?
基于 云服务，为 软件开发 和 Git 版本控制提供Internet托管平台
GitHub是一项基于 云服务，为 软件开发 和 Git 版本控制提供Internet托管平台。 这有助于开发人员存储和管理代码，同时跟踪和控制对其代码的更改。GitHub拥有超过1.5亿开发者，400万个组织机构，4.2亿个存储库。 [27-29]平台开发始于2007年10月，第一行代码在2007年10月提交到GitHub。              powered by [百度百科](https://baike.baidu.com/item/github/10145341#:~:text=GitHub%E6%98%AF%E4%B8%80%E9%A1%B9%E5%9F%BA%E4%BA%8E%20%E4%BA%91%E6%9C%8D%E5%8A%A1%EF%BC%8C%E4%B8%BA%20%E8%BD%AF%E4%BB%B6%E5%BC%80%E5%8F%91%20%E5%92%8C%20Git,%E7%89%88%E6%9C%AC%E6%8E%A7%E5%88%B6%E6%8F%90%E4%BE%9BInternet%E6%89%98%E7%AE%A1%E5%B9%B3%E5%8F%B0%E3%80%82%20%E8%BF%99%E6%9C%89%E5%8A%A9%E4%BA%8E%E5%BC%80%E5%8F%91%E4%BA%BA%E5%91%98%E5%AD%98%E5%82%A8%E5%92%8C%E7%AE%A1%E7%90%86%E4%BB%A3%E7%A0%81%EF%BC%8C%E5%90%8C%E6%97%B6%E8%B7%9F%E8%B8%AA%E5%92%8C%E6%8E%A7%E5%88%B6%E5%AF%B9%E5%85%B6%E4%BB%A3%E7%A0%81%E7%9A%84%E6%9B%B4%E6%94%B9%E3%80%82%20%5B21%5DGitHub%E6%8B%A5%E6%9C%89%E8%B6%85%E8%BF%871.5%E4%BA%BF%E5%BC%80%E5%8F%91%E8%80%85%EF%BC%8C400%E4%B8%87%E4%B8%AA%E7%BB%84%E7%BB%87%E6%9C%BA%E6%9E%84%EF%BC%8C4.2%E4%BA%BF%E4%B8%AA%E5%AD%98%E5%82%A8%E5%BA%93%E3%80%82%20%5B27-29%5D%E5%B9%B3%E5%8F%B0%E5%BC%80%E5%8F%91%E5%A7%8B%E4%BA%8E2007%E5%B9%B410%E6%9C%88%EF%BC%8C%E7%AC%AC%E4%B8%80%E8%A1%8C%E4%BB%A3%E7%A0%81%E5%9C%A82007%E5%B9%B410%E6%9C%88%E6%8F%90%E4%BA%A4%E5%88%B0GitHub%20%5B14%5D%E3%80%82)

# cloudflare
### 这又是什么？
Cloudflare，全称Cloudflare, Inc.，股票代码NET，股票简称Cloudflare Inc Class A，是美国一家主要经营信息科技服务的企业 [14]，以向客户提供网站安全管理、性能优化及相关的技术支持为主要业务 [26]，提供 DDoS 保护、网页应用程序防火墙等技术支持 [78]，成立于2009年，总部位于美国旧金山 [14]，创始人兼首席执行官为Matthew Prince  powered by [百度百科](https://baike.baidu.com/item/Cloudflare/17359757#:~:text=Cloudflare%EF%BC%8C%E5%85%A8%E7%A7%B0Cloudflare%2C%20Inc.%EF%BC%8C%E8%82%A1%E7%A5%A8%E4%BB%A3%E7%A0%81NET%EF%BC%8C%E8%82%A1%E7%A5%A8%E7%AE%80%E7%A7%B0Cloudflare%20Inc%20Class,A%EF%BC%8C%E6%98%AF%E7%BE%8E%E5%9B%BD%E4%B8%80%E5%AE%B6%E4%B8%BB%E8%A6%81%E7%BB%8F%E8%90%A5%E4%BF%A1%E6%81%AF%E7%A7%91%E6%8A%80%E6%9C%8D%E5%8A%A1%E7%9A%84%E4%BC%81%E4%B8%9A%EF%BC%8C%E4%BB%A5%E5%90%91%E5%AE%A2%E6%88%B7%E6%8F%90%E4%BE%9B%E7%BD%91%E7%AB%99%E5%AE%89%E5%85%A8%E7%AE%A1%E7%90%86%E3%80%81%E6%80%A7%E8%83%BD%E4%BC%98%E5%8C%96%E5%8F%8A%E7%9B%B8%E5%85%B3%E7%9A%84%E6%8A%80%E6%9C%AF%E6%94%AF%E6%8C%81%E4%B8%BA%E4%B8%BB%E8%A6%81%E4%B8%9A%E5%8A%A1%EF%BC%8C%E6%8F%90%E4%BE%9B%20DDoS%20%E4%BF%9D%E6%8A%A4%E3%80%81%E7%BD%91%E9%A1%B5%E5%BA%94%E7%94%A8%E7%A8%8B%E5%BA%8F%E9%98%B2%E7%81%AB%E5%A2%99%E7%AD%89%E6%8A%80%E6%9C%AF%E6%94%AF%E6%8C%81%EF%BC%8C%E6%88%90%E7%AB%8B%E4%BA%8E2009%E5%B9%B4%EF%BC%8C%E6%80%BB%E9%83%A8%E4%BD%8D%E4%BA%8E%E7%BE%8E%E5%9B%BD%E6%97%A7%E9%87%91%E5%B1%B1%EF%BC%8C%E5%88%9B%E5%A7%8B%E4%BA%BA%E5%85%BC%E9%A6%96%E5%B8%AD%E6%89%A7%E8%A1%8C%E5%AE%98%E4%B8%BAMatthew%20Prince%E3%80%82)

也是需要登录注册账号，其实就是你需要一些他们的服务，为了确保你是人类而验证你的身份,要使用*github*关联的方式(在works and pages 页面选择刚刚注册的github,再选择刚刚fork的项目)。在page和works界面选择你的githubfork的项目，然后构建它这会花一会时间

# dnshe
